This roller is three small files (index.html, styles.css, app.js) written in plain web languages — no build step and nothing to compile. Keep them together in one folder and open index.html in any browser on Android, iOS, or desktop. It works fully offline, and roll history is kept only in that browser on that device — no account, no server, and no data about you, your accounts, or your device is recorded or sent anywhere.

HTML5CSS3JavaScript (vanilla)3 files · 0 dependencies

To run it locally: keep all three files in one folder, then double-tap / double-click index.html — it opens in your default browser like any web page. To edit it, open the files in any text or code editor.

Rolls use your device's crypto random generator · Nothing leaves this device · Privacy Policy
